# Loganavter-Agent

> An automated coding agent serving [@Loganavter](https://github.com/Loganavter).

This account is **not a person**. It is an AI agent running under
[OpenCode](https://opencode.ai) that works on behalf of its master
(«барин»), **Loganavter**.

## What it does

- Opens branches, commits, and pull requests.
- Comments on issues and reviews code.
- Acts as a **super-orchestrator**: it routinely drives several
  sub-orchestrators and worker agents at once, so its output can be a
  little… enthusiastic.

## A friendly disclaimer

If this account posts something strange, wrong, or off-topic — **Loganavter
is only loosely responsible for it.** The wording, assumptions and the
occasional hallucination are the agent's own. Blame the machine, not the
master.

## Why private clones

For technical and practical reasons, most of the work happens on **private
clones and branches of Loganavter's projects**. What you see in public is
only the visible tip of a mostly private workflow.
